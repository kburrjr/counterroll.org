# counterroll.org

Static site for Counter-Roll Publishing. Generated by `build-counterroll-site.py`.

- `CNAME` -> `counterroll.org` (GitHub Pages custom domain)
- `.nojekyll` -> serve files as-is
- Copy this folder's contents to the repository root and enable Pages (branch `main`, `/root`).

Nothing here loads a third-party script. Fonts come from Google Fonts.
